**AUM-IC** no es un framework ni una librería. Es un **estándar arquitectónico estricto** diseñado para construir aplicaciones web de grado empresarial (Enterprise) que sean infinitamente escalables, predecibles y mantenibles.

Diseñado bajo el rigor de **INGENIERÍA CREATIVA Y DESARROLLOS TECNOLÓGICOS S.A.S. (IngCrea)**, AUM-IC fue forjado para resolver los problemas endémicos del desarrollo web moderno, devolviendo la cordura a la ingeniería front-end.

---

## ⚡ El Problema: El Caos Web Moderno

Si construyes aplicaciones web a gran escala, inevitablemente has enfrentado el colapso de la mantenibilidad. AUM-IC aniquila estos puntos de dolor universales:

1. **Sopa de HTML (El Cáncer de las Utilidades):** El abuso de frameworks (como Tailwind) que mezclan el estilo visual con la estructura, creando etiquetas HTML kilométricas imposibles de leer.
2. **Acoplamiento Fuerte:** Componentes que mezclan consultas a bases de datos (SQL/APIs) con el renderizado visual, violando el Principio de Responsabilidad Única.
3. **Caos de Directorios:** Proyectos donde es matemáticamente imposible saber dónde se ubica un componente o medir su nivel de complejidad a simple vista.
4. **Parálisis de Mantenimiento:** Arquitecturas donde cambiar un color corporativo o un texto multi-idioma obliga a los desarrolladores a reescribir cientos de archivos aislados.

---

## 🧬 La Solución: Una Síntesis Cósmica

AUM-IC resuelve estos problemas fusionando tres de los conceptos más robustos de la ingeniería de software en una analogía universal que cualquier desarrollador —o Inteligencia Artificial— puede comprender al instante:

*   **El Patrón MVC (Modelo-Vista-Controlador)**
*   **La Metodología Atomic Design (Diseño Atómico)**
*   **Los Principios de Clean Code (Código Limpio)**

---

## 📂 La Estructura Universal de Directorios

Bajo AUM-IC, el renderizado de interfaces abandona el caos y adopta un ensamblaje jerárquico estricto. Un componente superior puede contener a uno inferior, **pero jamás al revés.** 

Para garantizar el ordenamiento perfecto en cualquier editor de código, los directorios utilizan prefijos numéricos que representan la **Escala Cósmica**:

```text
src/
├── components/
│   ├── 1-atoms/         (⚛️ Átomos - Botones, Inputs)
│   ├── 2-molecules/     (🧬 Moléculas - Campos de Formulario)
│   ├── 3-cells/         (🦠 Células - Formularios Completos)
│   ├── 4-organisms/     (🦖 Seres Vivos - Bloques Interactivos)
│   └── 5-planets/       (🌍 Planetas - Macro-secciones Semánticas)
├── 6-layouts/           (☀️ Sistemas Solares - Plantillas Maestras)
└── pages/               (🌌 Galaxias - Controladores y Rutas)
```
